# 5-Stage-RISC-V-Processor

A SystemVerilog implementation of a 5-stage, single-issue RISC-V processor implementing a subset of the RV32I instruction set. The processor uses a pipelined datapath with hazard detection, forwarding, and pipeline flush logic to maintain correct instruction execution.
